What you are looking at

Every pixel is the average of many random light paths. Each path leaves the camera, bounces off matte walls, reflects off metal and refracts through glass until it reaches a light. One path per pixel looks like static. A few hundred converge to soft shadows, colour bleeding, caustics under the glass and real depth of field.

The image sharpens the longer you leave it still. Move the camera and it starts over at low resolution so you can aim, then refines.

How the browser runs Rust

The tracer is a Rust library with no dependencies. The same code builds a native command-line renderer and this 80 KB WebAssembly module, which talks to JavaScript through about a dozen plain extern "C" functions. No wasm-bindgen.

One Web Worker per CPU core renders strips of rows. The page adds their results into a buffer inside the module's own memory and calls tonemap() to turn it into pixels. Each sample's random seed comes from its pixel and index, so it never matters which worker drew what.
